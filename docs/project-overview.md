# Wholesale Distribution Management System

## Project Overview

The Wholesale Distribution Management System is built using
ERPNext and Frappe Framework.

The system manages wholesale business operations, including
purchasing, sales, inventory, suppliers, customers and accounting.

## Business Objectives

- Centralize business operations.
- Manage suppliers and customers.
- Track inventory across warehouses.
- Automate purchase and sales processes.
- Maintain financial transactions.
- Generate business reports.

## Company

Global Wholesale Traders

## Technology Stack

- Frappe Framework
- ERPNext
- Python
- MariaDB
- JavaScript
- HTML
- Git and GitHub

## Core Modules

1. Stock
